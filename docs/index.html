系統架構 Architecture

  • 資料層：yfinance（股票/ETF/黃金/白銀/原油/外匯）+ ccxt（加密貨幣 OHLCV / Funding Rate / Open Interest）+ FRED（總經數據，選用）+ Fear&Greed Index
  • 特徵工程：EMA/SMA/MACD/ADX/RSI/ATR/布林通道/Keltner/Donchian/Ichimoku/SuperTrend/PSAR/OBV/MFI/CCI/Stochastic/樞紐點/VWAP 等 20+ 技術指標，加上市場結構（BOS/CHoCH/FVG/Order Block/流動性掃蕩）、多週期趨勢一致性、時間特徵、滯後與滾動統計，共可擴充至數百個特徵
  • 市場狀態偵測：自動判斷牛市 / 熊市 / 盤整 / 高波動 / 低波動並動態調整策略權重
  • 策略引擎：趨勢跟隨、均值回歸、突破、動量四種規則式策略 + XGBoost/LightGBM/RandomForest 投票集成模型，依市場狀態加權投票產出最終 BUY/SELL/HOLD 訊號
  • 風險管理：Kelly Criterion、固定比例、ATR 動態部位、追蹤停損、VaR/CVaR、最大回撤熔斷、破產風險估算
  • 回測系統：向量化回測、Walk-Forward 驗證、Monte Carlo 模擬，含手續費/滑價成本
  • 執行層：預設僅 Paper Trading 模擬撮合；Alpaca / 加密貨幣交易所實盤介面已預留，需自行設定 API 金鑰才會啟用
  • 自動化：GitHub Actions 每日排程重新抓資料、計算訊號、更新本頁面

原始碼： src/ 目錄，模組化拆分為 data / features / models / strategies / regime / risk / backtest / portfolio / broker / alerts / pipeline / api。
