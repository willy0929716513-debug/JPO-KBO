系統架構

  • 資料層：yfinance（股票/ETF/黃金/白銀/原油/外匯）+ ccxt（加密貨幣）+ FRED（總經數據，選用）+ Fear&Greed Index
  • 特徵工程：20+ 技術指標 + 市場結構分析 + 多週期趨勢，可擴充至數百個特徵
  • 策略引擎：趨勢跟隨、均值回歸、突破、動量、統計套利（配對交易）+ ML 集成模型
  • 多代理決策系統：技術面 / 總經 / 風控 Agent 各自表態，風控 Agent 可直接否決進場
  • 風險管理：Kelly Criterion、VaR/CVaR、風險平價、每日/週/月虧損上限、最大回撤熔斷
  • 回測系統：向量化回測、Walk-Forward、Monte Carlo，20+ 績效指標
  • 執行層：預設 Paper Trading 模擬；Alpaca / 多交易所 / IBKR 實盤介面已預留但預設關閉
